Make your site AI-ready

When people ask Claude, ChatGPT or another assistant about your business, the assistant answers from what it can read. A LAWP file tells it exactly what you offer, your hours and what people can do (book, buy, get in touch). On most website builders it's one line of code, and it's free.

1. Your LAWP file is ready

Actuent has already made one from your site. See it at https://api.actuent.ai/lawp/YOURDOMAIN.json (put your domain in, e.g. api.actuent.ai/lawp/vega.dk.json). To change what it says, claim your site in Actuent Analytics and edit it there: the file updates by itself.

2. Point to it from your site

Add this one line to your site's head (replace YOURDOMAIN):

<link rel="lawp" href="https://api.actuent.ai/lawp/YOURDOMAIN.json">

Squarespace

Settings → Advanced → Code Injection → Header → paste the line → Save.

Wix

Settings → Advanced → Custom Code → + Add Custom Code → paste the line → Add code to pages: All pages → Place code in: Head → Apply.

Webflow

Site settings → Custom code → Head code → paste the line → Save → Publish.

Shopify

Online Store → Themes → … → Edit code → layout/theme.liquid → paste the line just before </head> → Save.

WordPress

Install the free Actuent LAWP plugin instead: it publishes the file itself at /.well-known/lawp.json and keeps it up to date.

Any other site

Upload the file to /.well-known/lawp.json on your site, or add the line above to every page's head.

3. Check it

Run the AI-ready checklist on your site. Actuent picks up the link on its next visit (within a day) and your site is marked as publishing its own LAWP, which helps it come up in AI answers. Show it with the live badge:

<img src="https://api.actuent.ai/badge.svg?domain=YOURDOMAIN&lawp=1" alt="LAWP">

Ranking on Actuent is never for sale. A LAWP file helps because assistants can read your site correctly, not because anyone paid.
