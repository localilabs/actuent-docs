Actuent for Discord

Type /actuent query: vegan restaurants copenhagen in any channel, and Actuent answers there: sites, what they do, products and prices. Free, no account. You make your own small Discord app (5 minutes), so nothing is shared with anyone else.

Set it up

  1. Open the Discord Developer Portal → New Application, name it “Actuent”.
  2. On General Information, copy the Public Key, and set Interactions Endpoint URL to:
    https://api.actuent.ai/api/discord/your public key
    then Save (Discord checks it straight away).
  3. On Bot, press Reset Token and copy the token (you only need it for the next step; Actuent never sees it).
  4. Add the command once, from a terminal (put in your Application ID and token):
curl -X POST "https://discord.com/api/v10/applications/APPLICATION_ID/commands" \
  -H "Authorization: Bot BOT_TOKEN" -H "Content-Type: application/json" \
  -d '{"name":"actuent","description":"Search the web as AI agents see it","options":[{"type":3,"name":"query","description":"What to search for","required":true}]}'
  1. On OAuth2 → URL Generator, tick applications.commands, open the link and add the app to your server.
  2. In a channel: /actuent query: running shoes under 800 dkk.

What's sent: the words you search for, and Discord's reply details for that one message. Actuent doesn't see your messages, channels or members. Every request is checked with your app's public key.
